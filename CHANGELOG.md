# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Public Go library at `github.com/VPSMarket/vminfo` for collecting host and process data.
- CLI commands for `summary`, `watch`, `ps`, `kill`, and `version`.
- Bubble Tea / Lip Gloss terminal UI with overview and process views.
- Embedded web dashboard with `--web`, REST endpoints, and WebSocket streaming.
- JSON outputs suitable for automation and integrations.
- English-first README, platform compatibility notes, and usage examples.
- MIT license and GitHub Actions based verification workflow.

### Changed
- GitHub is now the primary public source of truth for the project.
- Repository documentation now points to the public GitHub workflow and avoids private deployment helpers.
